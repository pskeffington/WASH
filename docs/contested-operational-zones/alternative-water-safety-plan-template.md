# Alternative Water Safety Plan (A-WSP) Template

## Purpose

This template adapts WHO Water Safety Plan principles to small, alternative, emergency, and contested-zone water systems. It is designed to consume findings from the pallet/rubble sanitary inspection form and convert them into a repeatable management loop:

```text
HAZARD
  ↓
CONTROL MEASURE
  ↓
OPERATIONAL MONITORING
  ↓
CORRECTIVE ACTION
  ↓
VERIFICATION
  ↓
USE CLASSIFICATION
```

This is a project template, not an official WHO Water Safety Plan form.

# 3. Hazard inventory

Use the sanitary inspection form and source-risk matrix to identify hazards.

## Hazard categories

### Source hazards

- sewage contamination;
- floodwater intrusion;
- salinity;
- nitrate;
- industrial contamination;
- hydrocarbons;
- unknown source history.

### Catchment hazards

- dust;
- fecal material;
- ash/smoke;
- unsuitable coating;
- corroded metal;
- damaged liner;
- contaminated rubble contact.

### Storage hazards

- unknown barrel prior use;
- open lid;
- unscreened vent;
- hand dipping;
- flood contact;
- dirty spigot;
- raw/treated mixing.

### Treatment hazards

- filter bypass;
- cracked ceramic;
- membrane failure;
- media disturbance;
- excessive turbidity;
- incorrect disinfectant use;
- inadequate contact time;
- exhausted media.

### Structural hazards

- rubble settlement;
- wind instability;
- barrel stand failure;
- damaged guying;
- overflow erosion.

# 6. Operational monitoring plan

## Minimum parameters

Where appropriate:

- captured volume;
- flow rate;
- turbidity;
- pH;
- conductivity/TDS;
- chlorine residual;
- microbial indicator;
- filter condition;
- liner integrity;
- storage closure;
- rubble/stand settlement.

## Sampling points

```text
S0 source / rainfall control
S1 pre-first-flush runoff
S2 post-first-flush raw storage
S3 post-settling
S4 post-roughing
S5 post-primary filter
S6 post-disinfection
S7 post-storage
```

## Monitoring schedule

### Event-based

- first storm after installation;
- major dust/demolition event;
- flooding;
- sewage intrusion;
- fire/industrial release;
- liner repair;
- filter maintenance;
- source change.

### Routine

Define locally appropriate frequency for:

- visual inspection;
- turbidity;
- residual disinfectant;
- microbial testing;
- storage hygiene;
- structural stability.

# 7. Trigger and action matrix

| Trigger | Immediate action | Follow-up |
|---|---|---|
| Sewage/flood contact | isolate source/system | clean, disinfect as appropriate, reinspect, retest |
| Positive microbial indicator after final treatment | stop drinking-water classification | investigate treatment/storage, apply validated corrective treatment, retest |
| Sudden filter flow increase | stop higher-use claim | inspect bypass/cracks/seals |
| Sudden turbidity increase | downgrade use | inspect source, pretreatment, media, bypass |
| Conductivity/TDS rises unexpectedly | isolate source if possible | investigate salinity/source mixing/chemical contamination |
| Liner failure | stop collection into potable pathway | repair/replace and reinspect |
| Barrel prior-use uncertainty | remove from drinking-water pathway | replace or formally characterize |
| Rubble stand settlement | unload/secure if safe | rebuild/level and recommission |
| Disinfectant residual outside accepted condition | stop higher-use claim | correct dose/process using validated protocol |
| Treated storage contamination | isolate treated vessel | clean/disinfect, correct storage failure, retest |

# 8. Corrective-action hierarchy

Use the least complex action that reliably restores control.

```text
1. STOP / ISOLATE
2. REPAIR / CLEAN
3. RE-TREAT
4. RETEST
5. RECLASSIFY
6. RETURN TO SERVICE ONLY WHEN EVIDENCE SUPPORTS IT
```

If evidence remains uncertain, downgrade rather than infer safety.

# 9. Verification plan

Operational monitoring asks whether the process appears to be under control.

Verification asks whether the system is actually achieving the intended result.

Verification may include:

- independent microbial testing;
- laboratory chemistry;
- comparison to direct-rain/source controls;
- filter integrity tests;
- review of maintenance records;
- repeated post-storage testing;
- external technical review.

# 10. Water-use classification decision

At each review, assign one status.

## REJECT

Use when:

- known hazardous chemical container;
- sewage/flood contamination not controlled;
- suspected asbestos/industrial contamination in water-contact pathway;
- treatment failure with unresolved risk;
- source chemistry incompatible with available treatment.

## NON-POTABLE / BOUNDED USE

Use when:

- collection is hydraulically functional;
- source/material risk remains unresolved for drinking;
- water may be suitable for defined non-potable uses.

## TREATMENT REQUIRED

Use when:

- source is usable but drinking-water treatment has not yet been completed or verified.

## TREATMENT RESEARCH ONLY

Use when:

- prototype performance is still being characterized;
- treatment chain lacks adequate verification.

## VALIDATED FOR INTENDED USE

Use only when:

- sanitary inspection is acceptable;
- control measures are functioning;
- monitoring is in range;
- verification supports the stated use.

# 14. Seasonal operating plan

For Gaza-like conditions:

## Winter

Prioritize:

- rain capture;
- storage maximization;
- overflow control;
- dust/first-flush management;
- storm structural checks.

## Summer

Prioritize:

- protected existing sources;
- stored/desalinated water;
- atmospheric-water research where productive;
- heat-safe storage;
- increased hygiene monitoring.

Seasonal operation should be based on local measurements rather than calendar alone.

# 15. Emergency fallback plan

If the primary system fails:

1. isolate affected source or component;
2. protect remaining clean storage;
3. switch to backup source if characterized;
4. downgrade intended use if necessary;
5. maintain non-potable supply where safe;
6. restore treatment/verification before upgrading use.

# 16. Transition to restored service

Alternative systems should not block transition back to stronger municipal/community service.

When centralized service returns:

- verify restored source quality;
- reconnect only after sanitary review;
- preserve alternative storage as reserve;
- preserve rain collection where useful;
- retain passive treatment as fallback if appropriate;
- document which emergency components remain active.

Final state:

```text
RESILIENT CENTRAL SERVICE
+
DECENTRALIZED BACKUP CAPACITY
```

## WHO / UNICEF alignment

This template follows the risk-management logic emphasized by WHO Water Safety Plans, WHO small-water-supply guidance, WHO rainwater sanitary inspection, and UNICEF emergency household water treatment and safe storage principles.

It is intentionally compact so it can be used in low-resource and emergency settings while preserving the essential sequence:

```text
UNDERSTAND THE SYSTEM
IDENTIFY HAZARDS
CONTROL RISKS
MONITOR OPERATION
ACT ON FAILURE
VERIFY PERFORMANCE
COMMUNICATE USE STATUS
```
